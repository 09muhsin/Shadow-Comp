# Shadow Company

Shadow Company lets founders rehearse tomorrow's company before making today's decision. It launches thousands of synthetic customers into a virtual SaaS/API business and shows the customer actions and operational events behind revenue, costs, support load, churn, and cash.

The MVP uses DocuFlow, a fictional document-processing API, to demonstrate how an unlimited `$19/month` plan can create rapid growth, infrastructure pressure, rate-limit failures, support overload, and high-value churn. Users can fork the future into alternative pricing and hiring decisions, then compare the outcomes.

GPT-5.6 is intended for structured business-model compilation, missing-assumption discovery, cohort hypotheses, and causal explanations. Codex accelerated the typed simulation engine, scenario modules, API contract, synthetic journeys, and automated tests. The accounting engine remains deterministic and independent from language-model output.

The project is fully runnable without API keys or production integrations. Its API demonstration uses an offline in-memory sandbox described by an OpenAPI contract.
