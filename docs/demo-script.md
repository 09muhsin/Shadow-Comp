# Three-minute demonstration script

1. Open the DocuFlow sample: two engineers, no support employee, `$19` unlimited Starter plan, and `$0.006` per processed page.
2. Run a seeded one-year simulation with 1,000 synthetic customers.
3. Show signups, usage costs, support tickets, infrastructure incidents, and churn on the timeline.
4. Pause on the first warning: high-volume customers create more infrastructure cost than subscription revenue.
5. Fork three futures: `$19` unlimited, `$19` usage-limited, and `$49` limited.
6. Compare customers, revenue, gross margin, churn, support backlog, cash, runway, and infrastructure failures.
7. Open one customer journey and show upload, usage pressure, support, and churn events.
8. Close with the visible disclaimer: scenarios are rehearsals, not guaranteed predictions.
